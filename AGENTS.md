# Repository instructions

This project belongs to `Nocs782/ai-generated-image-detection`.
The Git remote is `git@github.com:Nocs782/ai-generated-image-detection.git`.

- After completing requested project changes, run the relevant checks, review
  the changes, commit all new, modified, and deleted project files, and push to
  the current branch on `origin` before finishing. The user has requested this
  as the default workflow; follow a later instruction to leave work uncommitted
  or unpushed when given.
- Include source code, tests, documentation, split manifests, and small
  experiment records such as configs, training history, and evaluation metrics.
- Respect `.gitignore`. Keep raw datasets, ZIP archives, virtual environments,
  Python caches, model checkpoints, credentials, and local agent settings out
  of Git. Never force-add these files to satisfy the push instruction.
- Preserve existing commits and remote work. Do not force-push or rewrite
  shared history.
- Report the checks and pushed commit. If a commit or push fails, explain the
  blocker and retain the local work.
